# 🗣️ LingoBuddy: AI Chatbot for English Learners (A1–A2)

LingoBuddy is an AI-powered chatbot designed to help students practice English at CEFR A1–A2 levels. It offers friendly conversation, grammar correction, vocabulary quizzes, and listening practice—all in one simple web app.

## 🌟 Features

- 🤖 **Conversation Practice**: Chat naturally with an AI tutor
- ✍️ **Grammar Correction**: Get instant feedback and explanations
- 📚 **Vocabulary Quizzes**: Practice themed vocabulary with multiple-choice questions
- 🔊 **Listening Practice**: Hear English sentences spoken aloud
- 🧠 Powered by OpenAI GPT-4
